# Pre-report Checklist

## Universal
- [ ] Ticker valid on IDX; correct company (beware similar names/codes)
- [ ] Price data timestamp noted; not stale
- [ ] Liquidity: avg daily value, bid-offer spread in ticks
- [ ] Free float and major shareholders; recent insider/KSEI changes
- [ ] Board/notice status: UMA, FCA, special monitoring, suspension history
- [ ] Upcoming events: earnings, RUPS, ex-dividend, rights issue, lock-up expiry (post-IPO)
- [ ] Levels rounded to valid tick; stop based on ATR/structure
- [ ] Net R:R after fees/tax ≥ ~1.5 for a "buy" scenario, otherwise say why it isn't compelling

## Sector metrics
| Sector | Focus |
|---|---|
| Banks | NIM, NPL, CAR, LDR, CASA, cost of credit, ROE, PBV vs ROE |
| Coal / mining | Commodity price (HBA, Newcastle), strip ratio, royalty/DMO, export policy |
| Nickel / metals | LME nickel, smelter capacity, ore quota (RKAB), EV demand |
| CPO / plantation | CPO price, export levy, yield, weather |
| Consumer | Same-store growth, gross margin, volume vs price, purchasing power |
| Property | Marketing sales, rate sensitivity, land bank, debt maturity |
| Telco / infra | ARPU, capex, tower leasing, regulation |
| Tech / new economy | Cash burn, path to profit, take rate, lock-up |
| SOE | Government policy, dividend payout, holding-company impact, debt |

## Red flags
- Profit without operating cash flow; frequent related-party deals
- Auditor opinion issues, late financial report, going-concern note
- Sudden volume/price spikes on no news; heavy pledged shares
- Frequent rights issues, negative equity
